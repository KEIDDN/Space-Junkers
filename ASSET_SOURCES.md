# Asset sources

Everything the game ships with, where it came from, and its license.

## Characters (`Assets/LPC/`)

Every character (the operators, the crew, every enemy) and every piece of worn equipment is
drawn from hand-animated sheets of the **Liberated Pixel Cup** (LPC) and the **Universal LPC
Spritesheet Character Generator**:

- Source: https://github.com/liberatedpixelcup/Universal-LPC-Spritesheet-Character-Generator
  (and the OpenGameArt pages it links).
- Licenses, per file: CC-BY-SA 3.0 and GPL 3.0 for most; some parts also OGA-BY 3.0, CC-BY 3.0
  or CC0.
- Authors: bluecarrot16, Benjamin K. Smith (BenCreating), Eliza Wyatt (ElizaWy), JaidynReiman,
  Johannes Sjölund (wulax), Stephen Challener (Redshrike), Matthew Krohn (makrohn),
  Pierre Vigier (pvigier), Durrani, Evert, TheraHedwig, MuffinElZangano, Manuel Riecke
  (MrBeast), Marcel van de Steeg (MadMarcel), Michael Whitlock (bigbeargames), Thane Brimhall
  (pennomi), Sander Frenken (castelonia), Napsio (Vitruvian Studio), Nila122, Skorpio,
  Joe White, Luke Mehl, dalonedrau, laetissima, macmanmatty.
- `Assets/LPC/CREDITS.csv` lists the authors, licenses and source links for every sheet used.

Only the sheets the game uses are kept. `python3 tools/build_characters.py --fetch <checkout>`
copies them out of a checkout of the generator and rewrites the credits file.

`tools/build_characters.py` recolours them onto the game's palette, composes the gun-carrying
walk and run (the LPC hold torso over the walk and run legs), and packs
`public/assets/chars.{png,json}`. That atlas is a derivative work of CC-BY-SA / GPL art: it
must be distributed under a compatible license, with the credits file.

## Original project art (`Assets/`)

These are the project's own sheets. `tools/build_assets.py` cuts them into `public/assets/sprites.{png,json}` and never modifies the sources.

| Asset | Used for |
|---|---|
| `Main Character.png` | Muzzle flash, smoke and blood FX. (Its character frames are no longer used.) |
| `Tileset spaceship.png` | Floors, walls (plus recoloured palette variants per facility theme), doors, crates, barrels, ship and facility furniture |
| `Loot Objects.png` | Loot item icons |
| `Guns/Objects.png` | Ammunition, armor, helmets, backpacks, medical, grenades and tool icons; loot containers |
| `Guns/Guns/*.png` (Free Pixel Gun Pack) | Weapon sprites and weapon icons |
| `NPCs.png` | Crew portraits (dialogue), crew props (reused as facility furniture). (Its character frames are no longer used.) |
| `Planets.png` | Destinations |

Derived sprites (palette variants, tints, rotations, world-scale "deco" copies of item icons used as
set dressing) are generated by the build script from these sheets; nothing is hand-edited in the
atlas. The operator ID photos and searchable remains are cut from the LPC character sheets.

Stencilled wall signs are drawn at runtime with a hand-cut 5-pixel Cyrillic/Latin font
(`src/game/render/signs.ts`).

## Procedural art

Drawn in code at runtime, no source files: muzzle flashes (`src/game/fx/flashes.ts`), glows,
particles, casings, magazines, sparks, steam, dust, lamp fixtures, cables, map overlays.

**To confirm before a commercial release:** the Free Pixel Gun Pack arrived with the repository
without a license file. Check its author's terms (credit, commercial use) and record them here.

## Audio

Most of the game's sound is still synthesised at runtime with WebAudio (`src/engine/audio.ts`):
ambience beds, machinery, alarms, voices, UI tones, and the room reverb (its impulse responses are
generated, not recorded). Where a recording is clearly better (guns, boots, impacts, weapon
handling, a few interface switches) the game plays recorded takes, with the synthesised version
kept as the fallback if a file fails to load.

`tools/build_sfx.py` cuts, cleans (mono 48 kHz, trimmed, faded, peak -1 dBFS) and encodes the
recordings into `public/assets/sfx/` and the music into `public/assets/music/`. The raw packs are
not kept in the repository; download them from the links below to rebuild.
